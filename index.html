SOP Penanganan Gangguan OF Cut:
1. Terima Laporan: Catat waktu, lokasi, dan jenis gangguan.
2. Mobilisasi: Segera berangkat lengkap alat, material & APD.
3. Amankan Lokasi: Pakai APD lengkap, pasang rambu.
4. Identifikasi: Cek penyebab, foto kondisi awal & catat koordinat.
5. Ukur Titik Rusak: Pakai OTDR/OPM, simpan hasil ukur.
6. Siapkan Perbaikan: Siapkan kabel, joint closure & alat sambung.
7. Sambung Fiber: Lakukan fusion splicing.
8. Pasang Closure: Pastikan rapat, kedap air.
9. Uji Ulang: Ukur ulang dengan OTDR.
10. Bersihkan Lokasi: Rapikan area.
11. Lapor: Kirim data lengkap.
12. APD dibersihkan sebelum disimpan.

Tentang Web BUCIN

BUCIN
Barisan Utama Cegah Insiden Network

BUCIN adalah sistem informasi operasional terintegrasi untuk tim patroli jaringan fiber optik di wilayah Sulawesi Utara.

Fitur Utama
  • Dashboard statistik OF Cut
  • Peta interaktif & manajemen KML/KMZ
  • Filter titik peta per kategori
  • OPM/OLS dengan port 1-48
  • Inventaris Alker, Stok Spare, Patch Cord
  • Riwayat transaksi & audit log
  • Manajemen user & hak akses
Cakupan Wilayah
  • CLS MAMI
  • CLS Malalayang
  • DC Manado Centrum
  • CLS Kauditan
  • STO Bahu, Aermadidi
  • New Centrix Paniki
  • Rute OSP, IGG, DWDM, SEA-US
Teknologi
  • Firebase Realtime Database
  • MapLibre GL JS (Peta HD)
  • Chart.js (Visualisasi data)
  • QuaggaJS (Scan barcode)
  • SheetJS (Export Excel)
  • JSZip (KML/KMZ)
  • Tailwind CSS + Lucide Icons

Panduan Singkat
  1. Login dengan akun yang diberikan admin. Password default wajib diganti saat login pertama.
  2. Filter titik peta di dashboard untuk menampilkan kategori tertentu.
  3. Tambah data dengan tombol Tambah, isi form, dan pilih lokasi lewat peta.
  4. OPM/OLS — isi Dari/Ke/Nilai Kalibrasi, pilih port 1-48 lalu klik Submit Port, ulangi hingga selesai dan klik Submit Data.
  5. Export Excel kapan saja lewat tombol Excel di tiap menu atau per tabel.
